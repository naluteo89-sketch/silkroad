## B. 빌드 직전 Unity 설정 확인

- ⬜ `ComfyUI (설정)` → **Use Dummy 해제**, Server Url `https://cloud.comfy.org`, **Api Key 칸은 비움**
- ⬜ Key Status ✅ 확인 (`C:\keydata\comfy_key.py` → 빌드 시 apk 에 자동 포함, 빌드 후 프로젝트에서 자동 삭제)
- ⬜ `unity\Assets\StreamingAssets\ComfyUI\` 에 최종 워크플로·프리셋 JSON 이 있는지 (10/15 정리 후 비어 있음)
- ⬜ Workflow Path / Preset Path 확인. 출력 노드는 프리셋 `outputNode`("9") 가 우선 (Inspector Output Node Id 는 예비값)
- ⬜ 메뉴 **Silkroad → 액자 이미지 적용**, **두루마리 연출 추가** 등 아트 적용 후 씬 저장 (Ctrl+S)
- ⬜ Package Manager 에서 **In App Purchasing 제거** (지원 종료 경고, 미사용)
- ⬜ Console 빨간 오류 0개

## C. 안드로이드 빌드

1. ⬜ File → Build Profiles → **Android → Switch Platform**
2. ⬜ 메뉴 **Silkroad → 안드로이드 태블릿 설정 적용** (가로 고정, IL2CPP/ARM64, http 허용)
3. ⬜ Player Settings: Company/Product Name, 아이콘, 버전(Version / Bundle Version Code 매 빌드 +1)
4. ⬜ 태블릿 개발자 모드 + USB 디버깅 → **Build And Run**
5. ⬜ 배포용이면 Keystore 서명 설정 (분실 주의, 저장소에 올리지 않음)

## E. 운영 / 보안 ⚠️

- ⚠️ **API 키가 apk 안에 들어감** → 체험 전용 키 + Comfy 계정에 사용량/결제 한도 설정. 기기 분실 시 키 폐기·재발급
- ⚠️ 채팅에 노출됐던 키(`comfyui-01f8…`)는 폐기 완료 여부 확인
- ⚠️ Comfy Cloud 구독(Pro) 유지·크레딧 잔액 확인 — 만료 시 생성 실패(402/429)
- ⚠️ Comfy Cloud API 는 "실험적" → 행사 전 최신 상태로 1회 이상 리허설
- ⬜ 행사장 Wi-Fi 에서 cloud.comfy.org 접속 가능 여부 (방화벽/캡티브 포털)
- ⬜ 결과 이미지 보관·삭제 정책 (기기 내부 저장, 개인정보 없음)

## F. 남은 개발 작업

1. ⬜ 새 ComfyUI 워크플로 적용 (자리표시자: 입력 이미지, 프롬프트, seed, steps, cfg) + 품질 검수
1-1. ✅ **랜덤 액자** 구조 완료 (결과마다 Art/Frames 의 액자 중 하나, 창 위치 자동 인식) · ⬜ 액자 이미지 목록 수령 후 추가 · ⬜ (선택) 저장 파일에도 액자 합성
1-2. ⬜ **프롬프트 과보정 문제** (어떤 그림이든 지나치게 다듬어 원본 느낌이 사라짐) — 10/15 13시 이후 논의
1-3. ✅ 기존 Flux/SDXL 워크플로·프리셋 정리 (10/15)
2. ⬜ 두루마리 GIF → PNG 시퀀스 재생 컴포넌트, 시작 화면/그림판/결과 배경 적용
3. ⬜ 버튼·로딩 아트 적용, 레이아웃 미세 조정 (2000×1200)
4. ⬜ 비교 막대 손잡이 디자인(대나무 막대 등)
5. ⬜ (선택) 저장 결과 QR 다운로드, XR 전달(XRResultBridge)

## G. 알려진 이슈 / 메모

- 씬 자동 생성(`Silkroad → 씬 자동 생성`)은 **다시 누르면 꾸민 내용 초기화** — 아트 적용 후에는 사용 금지
- 실행 중(▶)에는 스크립트 변경이 반영되지 않음 → 반드시 멈춘 뒤 확인
- 앱 내 설정(PlayerPrefs)이 Inspector 값보다 우선 — 빌드 후 기기에서 설정 창으로 확인
