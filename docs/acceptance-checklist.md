## 생성 품질 (1단계)

대표 그림 10종 × seed 3개 = 30건. `python tools/comfy_batch_test.py --seeds 3` 결과의 `results.csv` 판정 칸을 채운다.

- 그림 구성: 선화만 / 단색 채색 / 복잡한 채색 × 인물·동물·건축·문양 (현재 `shared/test-drawings` 에 영상 기반 2종, 8종 추가 필요)
- 판정: 주요 대상·좌우 배치 유지, 색상 반영, 문화 스타일 적절성, 심한 형태 훼손 없음
- **목표: 30건 중 24건 이상 ‘체험에 사용 가능’**
